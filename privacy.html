プライバシー ポリシー

「Ace Drive Reader」（以下「この接続」）は、開発者本人が個人で使う AI 秘書「Ace」に、Google Drive のファイル、Gmail のメール、Google カレンダーの予定を読ませるための接続です。使うのは開発者本人だけです。

読み取る情報

この接続は、Ace 用の Google アカウントから見える Google Drive のファイルの名前・種類・更新日時などの情報と、ファイルの中身を読み取ります。Google ドキュメントは Markdown、スプレッドシートは CSV、スライドは文字として読みます。ファイルの作成・変更・削除・移動・共有は行いません。

Gmail については、Ace 用の Google アカウントに届いたメールの件名・差出人・宛先・日時・本文と、添付ファイルの名前・種類・大きさを読み取ります。添付ファイルの中身は読みません。メールの送信・返信・転送・削除・ラベルの変更は行いません。

Google カレンダーについては、Ace 用の Google アカウントから見えるカレンダー（開発者本人が共有したものを含む）の予定の名前・日時・場所・参加者・メモを読み取ります。予定の作成・変更・削除、招待への返事は行いません。

使う目的

読み取った情報は、開発者本人の仕事を助けるため（要約、仕事の整理、返信や更新の下書き）だけに使います。広告、販売、利用者の追跡には使いません。

送る先

  • Anthropic（Claude API）: 要約や下書きを作るために、読んだ内容を送ります。Anthropic の商用の利用条件では、API に送った内容は AI の学習に使われません。
  • Slack: 結果を、開発者本人だけが使う Slack のワークスペースに届けます。

このほかの第三者への提供、共有、販売は行いません。Google の API から得た情報を、汎用の AI モデルの開発・改良・学習に使うことはありません。

Google の API から得た情報の扱い

この接続が Google の API から受け取った情報の利用と、ほかのアプリへの受け渡しは、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

保存と削除

認可の情報（token）は、開発者本人の Mac の中にだけ保存します。読み取ったメールや予定を、この接続が別の場所に保存することはありません。Ace が作った要約やメモは、開発者本人の作業用フォルダに残ることがあり、開発者本人がいつでも削除できます。利用者は、Google アカウントの「サードパーティ製のアプリとサービス」から、この接続に与えた許可をいつでも取り消せます。
